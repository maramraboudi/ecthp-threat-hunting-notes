# Contributing

Corrections and additions to these learning notes are welcome. Keep material original, source-cited, defensive, and clear about uncertainty.

- Link to current primary references for technical claims.
- Do not copy course slides, textbooks, proprietary diagrams, exam items, or answer keys.
- Do not include credentials, personal data, unapproved indicators, or real incident evidence.
- Keep hands-on examples limited to synthetic data or explicitly authorized labs.
- Check local Markdown links and run `git diff --check` before submitting.

This repository is an independent study guide, not official certification content.
